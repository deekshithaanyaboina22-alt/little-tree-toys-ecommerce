# Little Tree Toys – Full Stack E-Commerce Website

## Project Overview

Little Tree Toys is a full-stack e-commerce web application built for a wooden toy brand. The platform allows users to browse products, manage wishlists and carts, place orders, update profiles, and track purchases through a modern and responsive user interface.

The project was developed using React for the frontend, Node.js and Express for the backend, MongoDB for data storage, and JWT Authentication for secure user access.
